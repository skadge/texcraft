- 2026-11-27: **Missing packages in the browser** (W8). The browser's engine downloads the TeX Live packages a document needs and its own TeX tree lacks, from a CORS-enabled mirror of TeX Live by year and snapshot (`https://texlive.skadge.org/tlnet/<year>/<snapshot>/`, tlnet's layout; `<year>/current` names the newest snapshot). retex's module is now built with its `download` feature (`cargo xtask retex-wasm`; the stamp holds the features, so a cached module without them is built again) and runs native retex's miss hook over a repository directory the worker serves (`RETEX_REPOSITORY=/tlnet/<snapshot>`, retex 2.5's R14): an open under it the file system lacks asks the host (`texcraft_wasi::Platform::missing`: absent, unavailable as `EIO`, or a stop to fetch it), the run stops, the worker fetches the file (with the database's other two files for one of them), adds it and starts the run again, as it does for the tree's files. retex checks the database's signature and each archive's SHA-512, unpacks the run-time files into `/cache/texlive/<year>/`, and asks for the archives in the snapshot its database came from (its `tlpdb/repository`), so `current` is asked only while retex keeps no database; an archive missing from that snapshot when the server has a newer one drops the database, fetched again next build. The packages and the database are kept in a Cache Storage cache per TeX Live year (`texcraft-packages-<year>`), not the engine's (named after the module), so an update of TeXCraft does not download them again. **The year**: `cargo xtask tree-site` now reads the installation's `release-texlive.txt` (CI's `texlive/texlive:latest`: TeX Live 2026), stages it for the seed's runs, and writes `seed/version.txt` (`retex 2.5.2`, `texlive 2026`, retex's R17 format); the worker writes `/texlive/release-texlive.txt` from it, so the module's year is the tree's and not the LaTeX kernel's date (the year before's in the months after a release), and downloads only that year's database (retex refuses another). **A good client** (`texcraft_compile::packages::Downloads`): one request at a time, only the database's three files and `archive/<package>.tar.xz` under a valid snapshot, each URL at most once a visit (a 404 is remembered), timeouts (15 s for `current`, 120 s for a file); a 429 holds every request back for its `Retry-After` (60 s when the browser cannot read it), a 503 for ten minutes, no answer or another error for two, at most an hour; the build goes on without the package. **Telling the user**: retex's `package-download` records are passed on while the worker fetches (`Event::Package`): "Downloading the LaTeX package epigraph (12 kB)…", "Downloading the list of TeX Live packages…";
