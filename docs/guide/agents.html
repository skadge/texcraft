Agents and automation Desktop only

Every action of TeXCraft's menus is a command, and agents and scripts can run the same commands. They reach what the interface reaches, and nothing else.

The MCP server

The command-line tool includes a server for the Model Context Protocol (MCP), which many AI agents and coding assistants speak. It works without a window, on project folders:

texcraft-cli mcp --automation-read-root DIR --automation-write-root DIR
  • --automation-read-root names a folder the agent may read, and --automation-write-root one it may change. Both can be given more than once.
  • It refuses to start without both, and refuses any file outside them, so an agent cannot wander through your disk.
  • It talks over its standard input and output, as MCP clients expect: register it in your agent's settings as a command to run. For example, with Claude Code: 
    claude mcp add texcraft -- /path/to/texcraft-cli mcp --automation-read-root /work/thesis --automation-write-root /work/thesis

The server offers two tools: command_list, which describes every command with its parameters and whether it can run now, and command_run, which runs one. An agent opens a project with project.open, edits with file.edit, builds with build.compile and reads the messages, and can comment with review.comment or propose a change with review.suggest, which you then accept or reject as any suggestion.

From the AppImage, make a link named texcraft-cli to it and run that: ln -s TeXCraft-*.AppImage texcraft-cli, then ./texcraft-cli mcp ….

The control channel of an open window

Started with texcraft --control, the desktop app also listens on this computer only (from port 7841) for requests to run its commands, so scripts and tests can drive the window you are looking at. A connection must first give a token that each start writes to a file only you can read. The protocol is described in docs/control-protocol.md.

What agents cannot do

  • Reach files outside the folders they are given.
  • Turn on AI requests or agree to send text on your behalf: they can only switch kinds of request off (AI privacy).
  • See your tokens or sign-ins: these never appear in a command's result.
