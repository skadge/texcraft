Settings

Open the Settings dialog with Edit › Settings… (Ctrl+,), or the Settings button at the bottom of the rail. Changes apply at once; there is nothing to confirm.

Your settings are kept on your computer (where), or in the browser for the browser version. A few things belong to a project rather than to you, and are kept in its .texcraft folder: its own spellings and whether AI may be used for it.

Appearance

Theme
System (light or dark as your system is set), Light or Dark.
System title bar Desktop only
TeXCraft draws its own title bar, with the window's buttons in the top bar. Tick this to have your system's title bar instead.
Show tips at startup
The tip of the day on the start page (see The start page).
Interface language
The language of the menus and messages: English, Deutsch, Español, Français, Italiano, Nederlands or Português, or as the system is set. The translations are new: a text not translated yet shows in English.

Editor

Save automatically
On by default: changes are written shortly after you stop typing, and versions are kept by themselves (History). Off, File › Save saves, and closing asks about changes not saved.
Font size
The size of the source text, in points, from 10 to 22; the formatted view's text follows it. Ctrl (Cmd on a Mac) with the mouse wheel over the text, or a pinch, changes it too, as do Larger Text, Smaller Text and Default Text Size in All Commands.
Editor key bindings
Standard editing keys, or Vim (Vim mode).
Close brackets and environments
Typing (, [ or { adds the closing one, and \begin{…} its \end{…}.
Check spelling
Underline misspelled words. Commands, math and verbatim text are skipped (Spelling).
Spelling language
From the document (its babel or polyglossia language; when it names none, the interface's language as your system's region writes it, such as British English), or a language of your choice. The setting says which language is checked now. The status bar shows it too, and changes it from a menu.
Check comments
Also check the text after % in the source.

Building

Compile automatically
Build the PDF when typing pauses.
Pause before building
How long typing must stop before an automatic build.
Engine
How the document is typeset: Chosen from the document, LuaLaTeX or pdfLaTeX.
Stop at the first error
Otherwise the build goes on and reports every error.
Draft images
Draw images as framed boxes with their names, for faster builds.
PDF for
Screen; Accessible (tagged, PDF/UA, checked for screen readers); or Print (a PDF/X, checked as printers check it). See Building.
PDF/X standard, Bleed, Crop marks
Shown for Print: PDF/X-4 or PDF/X-1a, how far the art runs past the page's edges (printers often ask for 3 mm), and marks outside the bleed that show where to trim.
Hidden messages
The kinds of build message hidden with Hide Like This in the log, in this project and in all projects, each with Show Again (Hiding messages of a kind).

The Compile button's menu has the most used of these too.

Keyboard

Editor key bindings
The same choice as in the Editor tab.
Keyboard shortcuts
Change Shortcuts… opens the list of every command and its shortcut (Changing shortcuts).

Review

Your name
Shown with your comments, replies and suggestions. Suggest mode needs it.
Your key
Made on this computer with your first comment (or now, with Make Key). It tells your comments from those of someone else with the same name; others see a short form of it.

AI Desktop only

At the top, Use AI features: untick it and every AI feature is hidden and nothing is sent; the tab then shows only the switch (more). Below it, the connection to a model (endpoint, token, model), what may be sent with a switch for each kind of request, the prompts, the log of what was sent, the next words as you type, and the project's own switch. All of it is described on the AI assistance page. In the browser this tab says AI is not available there yet.

Accounts

Who you are signed in as on GitLab, GitHub and your organisation's servers, with Sign In and Sign Out for each, Add a GitLab Server…, Add a GitHub Enterprise Server… and Remove Server. Servers your organisation provides are marked so and cannot be removed. Under Git servers, the servers whose token you chose to remember when importing a project (Overleaf's, any git server's), each with Forget. See Signing in, Your organisation's servers and Importing a project.
