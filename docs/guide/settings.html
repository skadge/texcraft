Settings

Open the Settings dialog with Edit › Settings… (Ctrl+,), or the Settings button at the bottom of the rail. Changes apply at once; there is nothing to confirm.

Your settings are kept on your computer (where), or in the browser for the browser version. A few things belong to a project rather than to you, and are kept in its .texcraft folder: its own spellings and whether AI may be used for it.

Finding a setting

The search field at the top of Settings finds settings in every section: type a word or two (Ctrl+F while Settings is open puts the keyboard in it) and only the settings whose name or explanation has them all are shown, under their sections' names, each one working where it is found. Capitals and accents do not matter, and in another language than English the English names find the settings too. A screen reader hears how many settings were found. Esc clears the search; a second Esc closes Settings. Each section, and each new search, starts at its top. Settings is as tall as the window, whichever section is shown.

A feature's quick choices elsewhere are the same settings: the Compile button's menu ends with Build Settings…, and the status bar's spelling language menu with Spelling Settings…, each opening the settings its choices come from.

Appearance

Theme
System (light or dark as your system is set), Light or Dark.
Dim the PDF in the dark theme
Off by default. On, while the theme is dark, the PDF's pages are shown a little darker than white, easier on the eyes in long sessions. The PDF itself does not change, nor what is printed or exported. Also Dim the PDF in the Dark Theme in All Commands.
Interface language
The language of the menus and messages: English, Deutsch, Español, Français, Italiano, Nederlands or Português, or as the system is set. The translations are new: a text not translated yet shows in English.
System title bar Desktop only
TeXCraft draws its own title bar, with the window's buttons in the top bar. Tick this to have your system's title bar instead.
Check for updates
On by default: shortly after the start, once a day, TeXCraft asks gitlab.com for its latest release (the GitHub mirror when gitlab.com cannot be reached); the browser version asks its own site for its version. Nothing about you is sent. The line under it says when the last check answered. Off, nothing is contacted; Help › Check for Updates… still checks when you ask. See Updates.
Show tips at startup
The tip of the day on the start page (see The start page).

Editor

Save automatically
On by default: changes are written shortly after you stop typing, and versions are kept by themselves (History). Off, File › Save saves, and closing asks about changes not saved.
Font size
The size of the source text, in points, from 10 to 22; the formatted view's text follows it. Ctrl (Cmd on a Mac) with the mouse wheel over the text, or a pinch, changes it too, as do Larger Text, Smaller Text and Default Text Size in All Commands.
Editor key bindings
Standard editing keys, or Vim (Vim mode).
Close brackets and environments
Typing (, [ or { adds the closing one, and \begin{…} its \end{…}.
Check spelling
Underline misspelled words. Commands, math and verbatim text are skipped (Spelling).
Spelling language
From the document (its babel or polyglossia language; when it names none, the interface's language as your system's region writes it, such as British English), or a language of your choice. The setting says which language is checked now. The status bar shows it too, and changes it from a menu.
Check comments
Also check the text after % in the source.

Building

Compile automatically
Build the PDF when typing pauses.
Pause before building
How long typing must stop before an automatic build.
Engine
How the document is typeset: Chosen from the document, LuaLaTeX or pdfLaTeX.
Stop at the first error
Otherwise the build goes on and reports every error.
Draft images
Draw images as framed boxes with their names, for faster builds.
PDF for
Screen; Accessible (tagged, PDF/UA, checked for screen readers); or Print (a PDF/X, checked as printers check it). See Building.
PDF/X standard, Bleed, Crop marks
Shown for Print: PDF/X-4 or PDF/X-1a, how far the art runs past the page's edges (printers often ask for 3 mm), and marks outside the bleed that show where to trim.
Missing packages Desktop only
What a build does when the document needs a package your TeX Live lacks: Download automatically (from TeX Live's repository for the year of your TeX Live), Install them myself (the message says how), Don't download, or Ask the first time until you choose (Missing packages).
Package server Browser only
Where the browser version downloads the packages its TeX tree lacks (Building).
Hidden messages
The kinds of build message hidden with Hide Like This in the log, in this project and in all projects, each with Show Again (Hiding messages of a kind).

The Compile button's menu has the most used of these too.

Keyboard

Editor key bindings
The same choice as in the Editor tab.
Keyboard shortcuts
Change Shortcuts… opens the list of every command and its shortcut (Changing shortcuts).

Review

Your name
Shown with your comments, replies and suggestions. Suggest mode needs it.
Your key
Made on this computer with your first comment (or now, with Make Key). It tells your comments from those of someone else with the same name; others see a short form of it.

AI Desktop only

At the top, Use AI features: untick it and every AI feature is hidden and nothing is sent; the tab then shows only the switch (more). Below it, the connection to a model (endpoint, token, model), what may be sent with a switch for each kind of request, the prompts, the log of what was sent, the next words as you type, and the project's own switch. All of it is described on the AI assistance page. In the browser this tab says AI is not available there yet.

Accounts

Your connections: every place TeXCraft reaches for you, and how. Each is a card with the service's mark, its name and address, who is signed in, its state in words (Signed in, Token, Signed out, Expired, Default) and where its sign-in or token is kept (the system's keychain; in the browser, this tab). GitLab, GitHub and your organisation's servers come first, then Other git servers (Overleaf, any other host). A GitLab sign-in that can only read says Read only until the first commit: the first commit asks once more.

Each card's buttons: Sign In with GitLab (or GitHub), Sign In Again when a sign-in expired, Allow Commits, Set as Default, Replace… for a token (the new one is asked for in place), Disconnect… and, for a server you added, Remove Server…. Disconnect asks first, then signs out (GitLab withdraws TeXCraft's access; on GitHub, remove it under your account's applications) and removes the token from the keychain. Projects linked to it stay as they are: their next Sync asks you to sign in. Servers your organisation provides are marked so and cannot be removed.

Add a Connection… offers the same cards as Import a Project: GitLab and GitHub (sign in, or a personal access token, which TeXCraft checks with the service before keeping it), a GitLab server or a GitHub Enterprise Server (TeXCraft says what to register there), Overleaf (its git token) and any other git server (its name and a token). In the browser, Overleaf, other git servers and GitHub Enterprise are marked Desktop app only: a web page cannot reach them.

The default connection is where new things go first: Import a Project opens on its card, and Save Project to GitLab or GitHub opens on it. See Signing in, Your organisation's servers and Importing a project.
