- 2026-11-24: Builds in the browser: TeXCraft's own build of retex's WebAssembly module (`cargo xtask retex-wasm`, the pinned release) runs in a Web Worker through `texcraft-wasi`, a WASI host in Rust, with the TeX tree of retex's site. A first build takes about 18 s, later ones 0.3 to 0.5 s from the preamble's snapshot. A file the run needs late stops it, and it runs again once the file is fetched.
