- C5 step 3 (docs/forges.md): GitHub as a second forge, with a personal access token (fine-grained: Contents read-only to open, read and write to commit, Pull requests read and write for a pull request; or a classic token with the repo scope). `texcraft-forge` is now written over a `Forge` trait (project, branch head and push rights, recursive tree, blob, one commit to a branch or a new branch from a start commit, a request to merge) with `GitLab` and `GitHub` implementing it and `Client` choosing by the address's new `service`; GitLab's behaviour and tests are unchanged. GitHub reads `GET /repos/{o}/{r}`, `…/branches/{b}`, `…/git/trees/{sha}?recursive=1` (a `truncated` tree refused in words) and `…/git/blobs/{sha}` (base64, checked against the id), and commits through the Git Data API: blobs, a tree on the parent's with `sha: null` deletions, a commit with the head as parent, then `PATCH …/git/refs/heads/{b}` without force; a 422 with the branch moved catches up as a pull does and makes the commit again (up to three times), with the head unchanged it is "cannot push". A protected branch is offered a new branch and `POST …/git/refs` + `POST …/pulls`. Errors in words name the service, GitHub's rate limit included (a 403 with `X-RateLimit-Remaining: 0`, the minutes until `X-RateLimit-Reset`). Addresses: github.com's pages and clone addresses are GitHub's, a bare `owner/repo` with `service: "github"`, another host chosen as GitHub is an Enterprise Server; links saved before are GitLab's. Engine: `forge.open` takes `service`, results and `forge.status` say it, commit links per service, command labels "… GitLab or GitHub…". Window: the open dialog has a GitLab / GitHub choice set by itself from gitlab.com and github.com addresses, the token's permissions explained per service, menus, dialogs, status line and top bar naming the service (Commit to GitHub…), the pull request's link after the new-branch path. Tests: the forge's open, pull, merge, conflict, commit, race, new branch and protected-branch tests run against a fake GitLab and a fake GitHub; GitHub's addresses, Git Data API commit, truncated tree, an unseen rule, rate limit and token (forge); open, commit and pull request through the commands (engine) and the dialogs (kittest).
