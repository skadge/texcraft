- 2026-11-24: New folders and moving files (P6). The file tree's header has New Folder… beside New File…, and a folder's context menu has New File… and New Folder… with the folder's path filled in; all go through `file.new_folder` (also in the File menu and the command palette, and for agents). A project stores files only, so a new folder is kept by the session until a file is in it: it is shown in the tree but not saved, and it does not make the project unsaved. A file row dragged onto a folder row, or onto the empty space below the rows (the top level), is moved there; an image dragged onto the source is still inserted. From the keyboard, a file's context menu has Move to…, which asks for the folder. Both go through `file.rename`, which keeps the open tab, the main-document mark and the comments' anchors, refuses to replace a file of the same name (and says so in the status line), and does nothing when the file is already there.
