- Project-wide search (E10): Edit › Find in Project or Ctrl+Shift+F (Cmd+Shift+F on macOS), command `view.find_in_project`, opens Search in the side panel (also a rail button and `view.side.search`) with the keyboard in its field, on the editor's one-line selection. It finds in every text file of the project, with Match Case, Regular Expression and Whole Word as in the find bar, and lists the matches grouped by file (a file's heading folds its matches), each with its line number and its line around the match, marked. Enter in the field goes to the first match; a click or Enter on a match opens its file at its line. Replace All, under Show Replace, first asks "Replace N matches in M files?" and then makes one edit per file, so in a file open in the editor Undo takes its replacements back in one step. The count is announced politely. Agents use the engine commands `project.find {pattern, regex, case, word}` (matches per file with line, column, text and the line before and after it, at most 10,000) and `project.replace {…, replacement, files?}`, which works every edit out before making any, so a failure changes no file.
