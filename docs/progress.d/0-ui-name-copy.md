- 2026-11-24: The project's name in the top bar is edited in place (click it, or Tab to it and press Enter; Enter keeps the name, Escape or leaving the field does not). An untitled project is saved under the name typed: in the browser at once, on the desktop in a new folder of that name, in a folder the user chooses. A saved project is renamed by `project.rename`: in the browser its stored copy, on the desktop its folder (refused when the name is taken or outside the automation roots). The build log's messages can be selected, and each has a button that copies it as `file:line: severity: message`; the messages shown and the raw log can be copied whole.
