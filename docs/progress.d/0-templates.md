- 2026-11-22: Publishers' templates. New Project opens a gallery of 15 templates (Elsevier, IEEE, ACM, APS, AAS, MNRAS, Nature, ACS, APA, ASME, moderncv, Europass, tikzposter) with search, categories, source and licence. A template is downloaded from TeX Live the first time it is used, checked against TeX Live's signed package database, and kept for offline use; agents use kept templates only.
