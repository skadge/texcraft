- O2, O3: a build makes one of three kinds of PDF (`build.options` `output`; Settings › Building › PDF for, and the Compile button's menu; kept in the preferences): for the screen (the default), accessible, or for print. An accessible build is retex's `accessible(true)` (`--accessible` in the browser): a tagged PDF that declares PDF/UA in its XMP, checked for what screen readers need. A print build also writes a PDF/X beside the PDF (`Retex::pdfx`, `-output-format=pdf,pdf-x4` in the browser), PDF/X-4 or PDF/X-1a (`pdfx`), with a bleed (`bleed_mm`, 3 mm by default, up to 20) and crop marks (`crop_marks`, on by default); the preview keeps showing the PDF as designed, so SyncTeX and the print checks' places match it, and Save PDF / Export › PDF write the PDF/X (`kind` in their result; a print build that wrote no PDF/X saves nothing and says why). The build log has an Accessibility filter (findings of origin `accessibility`) and a Print filter (`print` and `PDF/X` messages), shown for a build of that kind or one with such findings, each message linking to its source line; a print message whose check retex placed on the page also links to that page ("Page 2"), which shows the PDF with the area marked. A print build's log starts with "Ready for print" or "N problems" (warnings and errors of the print checks and the PDF/X, and a missing PDF/X). `Outcome` keeps the kind of PDF and a print build's `Preflight` (the PDF/X, its print checks with their page area and source place, the standard's rules); agents get `output`, `accessibility` and `print` (`ready`, `problems`, `checks`, `rules`, `pdfxBytes`) in `build.result`. retex 2.5.0's worker takes the PDF/X options but not `accessible`, so on the desktop an accessible build runs in process (without the worker's preamble snapshot); and retex rewrites LaTeX's tagging messages (an image without alternative text, formulas without MathML, the PDF's language, a class without tagging) with no origin, so TeXCraft gives those the origin `accessibility` itself (docs/retex-changes.md, R18 and R19).
