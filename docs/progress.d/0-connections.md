- 2026-11-27: Connections (docs/design/connections.md; C5, C11). **Settings › Accounts** is one list of every place TeXCraft reaches for the user: gitlab.com, github.com and each self-managed GitLab or GitHub Enterprise Server, then Overleaf's and other git servers, each a card with the service's mark, its name and address, who is signed in (their initial and "Ada Lovelace (@ada)"), its state as a badge in words (Signed in, Token, Signed out, Expired, Signing in…, Default), what it can do ("Read only until the first commit") and where it is kept (keychain, this tab, this session), with Sign In, Sign In Again, Allow Commits, Set as Default, Replace…, Disconnect… and Remove Server…; Disconnect and Remove Server ask first and say that linked projects stay and ask at their next Sync. With nothing connected the page says what connections are for, with a large **Add a Connection…**, whose dialog has Import's cards (GitLab, GitHub, GitLab Server, GitHub Enterprise Server, Overleaf, Other Git Server) and then the existing sign-in, server registration, or a token, a forge's checked with the service (`/user`) before it is kept; in the browser the git servers and GitHub Enterprise show as Desktop app only, with the reason. **The default connection** (one forge, `default_connection` in the preferences) is where Import a Project opens (its card focused and marked Default, a GitLab server's page on it) and Save Project to GitLab/GitHub starts (its connection list names who is signed in, the default first). Commands: `accounts.list` (never a token), `accounts.add`, `accounts.disconnect`, `accounts.set_default`, the UI's `app.add_connection`; `forge.remove_server` now also forgets the server's token and the default. Nothing kept moves: sign-ins, tokens, servers and hosts from earlier versions list as they are. "Forget" is now Disconnect… (it signs out too). Tests: the engine's `connections.rs` (the list follows sign-ins, tokens and servers and holds no token; Disconnect revokes and forgets; the default kept, restored and dropped with its server; a refused token not kept; earlier versions' sign-ins listed with no request) and the window's `connections.rs` (by keyboard: Add a Connection…, its cards and arrows, Escape giving the keyboard back; a git server connected and disconnected after asking; a GitHub token checked, set as the default, Import opening on it; a phone's list).
