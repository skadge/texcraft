- 2026-11-26: first catalogs for German, Spanish, French, Italian, Dutch and European Portuguese, drafted with an AI model (Claude) from the English alone and not yet reviewed by a native speaker (each catalog's header and `ATTRIBUTION.md` say so). Every plain string, command label, count and unit is translated except one (below); of the 594 engine messages, 360 to 433 per language, leaving out those meant for agents (parameter errors, tool descriptions), machine text (HTML, HTTP headers, JSON, search queries, git protocol) and the default commit messages ("Saved from TeXCraft", "Merge {remote}/{branch}"), which would otherwise show a commit's real message in another language. Coverage (`cargo xtask i18n-report`, of 2,099): es 1,937, fr 1,930, nl 1,920, de 1,900, pt 1,900, it 1,864. "Typing ( [ { adds the closing bracket, and \\begin{…} its \\end{…}." has no row: its bare `{` reads as a placeholder, so no translation can carry the same one.
