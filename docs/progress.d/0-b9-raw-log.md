- B9 (docs/ROADMAP.md): the raw log and outputs. The build log's Raw log has a search field ("Search the raw log"): matches are found ignoring the case of ASCII letters, counted ("2 of 3", "No results", announced through a live region), marked on the search colour with the current one on the selection colour and underlined (so colour is not the only signal), and scrolled to; Previous Match and Next Match go through them, Enter and Shift+Enter too, the field keeping the keyboard. Above it, **Output files** lists what the last build made: its PDF, a print build's PDF/X (`main-print.pdf`), the SyncTeX data and the raw log, each named after the main document, with its size, and Save As… (a native picker on the desktop, a typed path without one) or Download in the browser, and on the desktop Show in Folder once it was saved (the build keeps its files in memory: before a save the button says so), which the desktop shell does through craft-update's `process::reveal` (sandbox-aware; new dependency of `apps/texcraft` only, its new transitive crates all under allowed licences). Commands: `build.outputs` (the files, sizes and where each was saved) and `build.save_output {output: pdf|pdfx|synctex|log, path}` (in the browser, `path` is the download's name); interface commands `build.save_output {output}` (asks where) and `view.show_output {output}`. Tests: outputs listed and each saved as made, a failed build offering only its log (engine); searching the raw log counts every case of a word, Enter, Shift+Enter and Previous step through it; the build's files listed and the log saved where typed (kittest). The engine reports no other files of the build folder, so none are listed.
