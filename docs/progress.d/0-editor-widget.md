- 2026-11-22: TeXCraft's own source editor. The text is a rope with grouped undo (texcraft-buffer), laid out a line at a time, with the gutter, selection, IME and an accessible text node. Vim key bindings (texcraft-vim) can be chosen in Settings: modes, motions, operators, text objects including LaTeX environments and inline math, search, :s, registers, marks, macros; the mode shows in the status bar.
