- Every project a git repository (C8), desktop: a new crate `texcraft-history` (gitoxide, no network) keeps a project's history in git. Opening a folder finds the repository it is in; saving a folder that is in none makes one there (branch `main`, `.retex/` ignored, marked `texcraft.history = true` in its configuration), and each save that changes the project commits it ("Saved with TeXCraft", by the review name, else the repository's git identity, else TeXCraft); `project.save` says what was committed. A folder in a repository someone else made (its own or a folder's above it) is never committed on save, only with `history.commit`. A commit holds the project's files as the session has them and its review threads; hidden files, links and submodules keep their versions, untracked files the ignore rules leave out stay out, and the index is updated so `git status` agrees. Commands: `history.status`, `history.list` (newest first, with the files each commit added, changed or deleted), `history.show` (a file as at a commit), `history.restore` (a file or the whole project as at a commit, as unsaved edits the next save commits), `history.commit`. Agents reach only repositories inside their roots. Next: the History panel (C4) and the browser's history.
