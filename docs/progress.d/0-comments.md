- 2026-11-22: Comments. Select text and choose Edit › Comment (Cmd+Alt+M, or `:comment` in Vim): the thread appears in a margin beside its passage, which is tinted in the author's colour and marked in the gutter. Threads take replies, can be resolved (they fold) and reopened, edited and deleted by their author, filtered (all, open, resolved, mine) and visited with F8 and Shift+F8; a narrow editor shows them in the Review panel of the rail. They are kept in the project as `.texcraft/review/<id>.json`, one file per thread (docs/review-format.md), follow the text as it is edited, and come back on their passage when the project is reopened. Agents use the same `review.*` commands. The first comment asks for the name comments carry and makes a key that tells two people of the same name apart (Settings › Review).
