- 2026-11-26: Fixes from testing 0.15.0 (issues #28, #33, #36, #37, #38, #42). **Open Folder with a large file (#28):** a file over the 64 MB a project file may have (a reference PDF) made the whole folder fail to open, and the status gave a raw byte count. It is now left unread: the project lists it (`Project::not_loaded`; `project.open`'s `not_loaded` with each size, and `project.inspect`), saving leaves it untouched, it is not part of the build, and the status line names it with its size in units. Engine messages about sizes write units (`texcraft_project::size_words`), as does the pane of a binary file. A forge's file limit is now a project file's (64 MB, was 10 MB), as for a folder or zip import and a dropped folder; the engine checks the two agree when it is compiled. **British English (#36):** craft-proof already checks British English (SCOWL's en-GB when the build embeds craft-i18n's language data, else an installed Hunspell en_GB), and babel's `british`/`UKenglish` chose it; a document naming no language was checked in the interface's language, `en`, which is American. The fallback now carries the system's region (`en_GB.UTF-8`: en-GB), and polyglossia's `variant=british` (or `uk`, `american`…) chooses its English. **Spelling language in the status bar (#37):** after the file's language, the status bar says what spelling checks (English (United Kingdom), or Spelling off, a warning icon when there is no dictionary), with where the language comes from on hover; a click or Enter opens a menu of the document's language, the languages with a dictionary, and Off, through `language.spelling_options`. **Formatted view (#38):** a double-click selects the word, a triple-click the paragraph; Ctrl+double-click (Cmd on a Mac) goes to the source as the double-click did, and `view.show_in_source` (Edit › Go To, the text's context menu) takes the caret and selection to the source. **Text size (#33):** Ctrl (Cmd) with the mouse wheel, or a pinch, over the source or the formatted view changes the text's size within 10 to 22 points, kept in `editor_font_size`; the formatted view's text now follows that size in proportion; `view.text_larger`, `view.text_smaller`, `view.text_default` do it without the wheel (no default key: Ctrl+0, Ctrl+= and Ctrl+- zoom the PDF). **Fix everywhere (#42):** the hint popup's "Fix all hints in this file" applied the first fix of every hint, of every kind (retex's fix-all); it is now "Apply this fix everywhere in this file (n places)", the hint's own fix applied to each hint of the same kind (the same message), one per line, with `Fix::everywhere` (and `language.fixes`'s `everywhere`) giving the count. Tests: a sparse file over the limit opens, is listed, survives a save and is skipped alike by an import (engine), and the status gives its size in MB (kittest); the spelling fallback from a locale (unit), polyglossia's variants (latex), British and American documents with the real dictionary when a British one is there (engine); the status bar's spelling menu by pointer and keyboard (kittest); double- and triple-click selection, Ctrl+double-click and Show in Source (kittest); Ctrl+wheel over the text within bounds and not elsewhere (kittest); the fix everywhere leaves other kinds of hints alone (engine). Not yet: the release packages do not embed craft-i18n's language data, so without an installed Hunspell en_GB British and American English share the built-in word list; a large file the document includes (`\includegraphics`) is missing from the build.
