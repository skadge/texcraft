- 2026-11-25: A11, the user guide. `docs/guide/` is a static, multi-page HTML guide with one stylesheet and no scripts: an overview with downloads and what differs between the desktop and the browser, getting started (the start page, templates, the window, automatic builds), writing (the source editor, the formatted view and what it edits, tables, figures, symbols, spelling, find and search, folding, several carets, Vim mode), building and exporting (the Compile button's menu, the build log and its output files, source and PDF navigation, the preview, accessible and print PDFs, the Export menu), projects, files and history, GitLab and GitHub (signing in, opening, committing, updating, merge requests, push and pull, Save Project to GitHub or GitLab, self-managed servers and the organisation's `texcraft-forges.toml`), comments and suggestions, AI assistance (connecting, what each kind of request sends, prompts, every feature; desktop only), keyboard and accessibility (the default shortcuts from the command registry, F6's regions), settings tab by tab, agents (the MCP server and the control channel), and troubleshooting (common build errors, packages in the browser, installation, where settings, data and caches live on Linux, the Flatpak, macOS and Windows, logs). Labels and menu paths are the interface's; features only on the desktop or in the browser are tagged, unfinished ones are in "Not yet" notes. The pages follow the system's light or dark scheme, have a skip link, landmarks, a plain list of pages that wraps above the text on a phone, tables that scroll in their own frame, and 4.5:1 contrast for every text colour in both schemes; the pictures are the README's screenshots. Help › User Guide (`help.guide`, F1, which was free) opens the guide online at https://texcraft-893d51.gitlab.io/guide/, `{"page": "ai.html"}` one of its pages (anything that is not a page name falls back to the guide's start), and Settings › AI links its AI page; the packages carry no copy yet, so the desktop opens it online too. The `pages` job publishes it at /guide/ beside the web editor, with the README's pictures at /images/. `cargo xtask guide-check` (also in `cargo xtask ci`) checks every page's lang, title, h1 and main, alternative text on images, unique ids, every link to a file of the repository and every anchor, and that the overview links every page. Tests: Help › User Guide and F1 open the guide, a page parameter cannot leave it (kittest); a broken anchor, a missing alternative text, a missing file and a page the overview does not link are found (xtask).
