- Context menu in the text (E7): a right-click, Shift+F10 or the Menu key opens a menu with Cut, Copy, Paste and Select All, Add a Comment when text is selected, Quick Fix when the caret is on a problem, and Show in PDF. Each entry runs its Edit menu command and shows its shortcut; Cut, Copy and Paste are registered commands now (`edit.cut`, `edit.copy`, `edit.paste`) and in the Edit menu too, disabled without a selection. Opened from the keyboard, the menu's first available entry gets the keyboard, and Escape gives it back to the text. A right-click outside the selection moves the caret there first. Paste asks the window for the clipboard's text; in the browser, where a menu cannot read the clipboard, it is disabled and says to press Ctrl+V.
- Selections in Vim mode (E8): Edit › Comment (and the menu's Add a Comment, Cut and Copy) act on Visual mode's selection and then leave Visual mode as an operator does, with `'<` and `'>` set so `gv` selects the passage again. A selection dragged with the mouse in Insert mode no longer collapses: it ends the insert and becomes Visual mode's selection.
