- 2026-11-25: P10, folders and zip files. Dropping a folder (or choosing one) adds its files with their folders under the project's top level (`file.import` of a folder; `into` for another folder); a zip file is asked about — Unzip into the Project (the default, which has the keyboard), Add the Zip as a File, Cancel — and File › Import a Zip File… unzips without asking (`file.unzip {source | data, into, existing, check}`). Whatever the source (a folder on disk, a zip, the files a browser read from a dropped folder through the drop's entries, `webkitGetAsEntry`), the same rules apply (`texcraft_engine::import`): hidden entries (`.git`, `.DS_Store`, any dot name, `__MACOSX`, `Thumbs.db`) and build outputs (`.aux`, `.log`, `.synctex.gz`, `.fls`, `.fdb_latexmk`, `.out`, `.toc`, …) are left out; on disk, a link to a file of the folder is read and a link out of it or to a folder is not; a zip's names that would leave the project (`..`, absolute, a drive letter) and its symbolic links are left out, a zip whose entry expands more than 200 times (past 1 MB) is refused as a likely zip bomb, and the one folder all its files are in is taken off their paths; at most 5,000 files and 500 MB an import. Files already in the project: one question for the whole drop (Replace, Keep Both — the new one becomes `name-2.ext` — or Skip; `existing`), adding single files included, which replaced silently before. The status line says how many files came in and what was left out and why. On the start page, a dropped folder opens as a project (desktop), and a zip file or a browser's folder becomes a new, unsaved project (`project.import`), kept where the user then chooses (a folder on the desktop, a name in the browser). The drop overlay says what a drop will do. The zip reader is craft-zip's (`Archive`: entry-count guard, declared-size and budget checks), now an engine dependency on every target. Tests: a folder's structure, filtering and links, `into`, limits reported, replace / keep both / skip and `check` (engine); a zip's common folder, unsafe names, symlink entries, the zip bomb refused whole, a new project from a zip, a browser folder's files (engine); hostile zips and imports in the command sweep; the zip question by keyboard, Cancel, Add as a File and Keep Both (kittest).
