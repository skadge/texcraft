- B8: a better PDF preview. Pages are drawn on the page thread, those in view first and then those half a pane around them; before each page the thread takes what the view wants now, so pages scrolled away, drawings at a zoom left behind and pages of an older PDF are dropped instead of drawn. The browser draws one page a frame. The zoom menu (Fit width, Fit page, 50–400 %) runs commands: `view.fit_width`, `view.fit_page`, `view.actual_size` (Cmd+0) and `view.zoom {"percent": N}`, which the control channel runs with its parameter. Links: `texcraft_preview::Document::links` reads a page's link annotations (explicit and named destinations, GoTo and URI actions, name trees bounded for hostile files); each is a link widget (keyboard, screen readers, a hand and its target as a tooltip); a link to a page scrolls there, a web or mail address opens after craft-pdf's `safe_url` check, anything else is refused with the reason in the status bar. Text: `Document::glyphs` reads each glyph's box and characters through craft-pdf's page interpreter (spaces and line breaks put back from the gaps); a drag selects on one page, Ctrl+C copies, a click or Escape clears. Presentation mode: `view.present` (F5, or Present in the zoom menu) shows a page at a time in the whole window; arrows, Space, Page Up and Down, Home and End move, Escape leaves at the page presented. Not yet: a selection across pages, the reading order of multi-column pages other than TeX's, and a real full-screen window for presentations (it fills the window). The link and text readers belong in craft-pdf (AGENTS.md rule 9); moving them there is a follow-up.
