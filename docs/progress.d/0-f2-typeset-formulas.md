- F2: the formatted view draws formulas typeset by retex after the main document's preamble, on the desktop. `texcraft_compile::formulas` sends the formulas it has not typeset yet in one batch of retex fragments (one page each, as tight as its box) on a thread of its own, through a `retex worker` process of its own (a batch in the build's worker would stop a running build), or in process where there is no worker program (the CLI, tests); it keeps each by preamble, source and mode, so editing one formula typesets that one only. `Session::formulas` finds a file's formulas in its view model (display environments become one `aligned` or `gathered` formula without `\label`, `\tag` and `\nonumber`) and takes the body size from the class options. The view rasterises each page with craft-pdf as a coverage mask, drawn in the text's colour (a formula's own colours are lost), at the window's pixels per point, again when that changes; inline formulas sit on the text's baseline in a line tall enough for them, display formulas are centred and made smaller to fit the measure. While a formula is typeset it shows as its source; one with an error shows its source underlined, its tooltip retex's message. A typeset formula is an image named by its source for screen readers. Agents get the same with `language.formulas` (each formula's line, status, box in TeX points or messages). The browser has no engine for this yet: there formulas stay as their source and say so.
