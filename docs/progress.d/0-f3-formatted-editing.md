- F3, first step (docs/ROADMAP.md): the formatted view's text is edited in place, each key a minimal edit of the source. `texcraft_latex::edit` maps a text run's characters to the source they stand for (spaces, quotes, dashes, control symbols, `~` and the fixed-text commands included), makes the caret stops of a line (atoms — chips, formulas, what is shown as source, footnote marks, links — one stop on each side; where two runs meet, the caret stands at the end of the first, so typing continues the style before it), and makes the edits: typed and pasted text escaped (`# $ % & _ { }` with a backslash, `~ ^ \` as `\textasciitilde{}`, `\textasciicircum{}`, `\textbackslash{}`, which the view now shows as their characters), Enter (a paragraph break with the styles open at the caret closed and opened again, an empty paragraph at a paragraph's or a heading's end, a new `\item` in a list, nothing in a caption, footnote or formula, said on the status line), a selection deleted run by run so the source stays balanced, the break between two paragraphs deleted to join them, Bold and Italic wrapping each selected run (or the word at the caret) or unwrapping it, the heading levels renaming a heading's command or making a paragraph one, Bulleted and Numbered list renaming a list or making a paragraph its item. The view (`formatted_edit`) edits the source editor's buffer, so edits go to the session as typing does in the source (`file.edit`, origin `local`) and undo is shared with source mode; the caret and selection are the buffer's, kept by source offset across the view being made again. Keys: arrows, Ctrl/Alt+arrows by word, Home/End (row; with Ctrl the text), Up/Down across rows and paragraphs, Shift to select, Ctrl+A, Ctrl+Z/Y; the pointer places the caret and drags a selection across paragraphs; double-click still shows the source there. Backspace or Delete next to an atom selects it and a second press deletes its source. A paragraph only the caret shows (just made with Enter) is drawn empty with its caret. Accessibility: the view is an editable multi-line text node (`main.tex formatted`) with its value, caret and selection, one text run per line. With Vim's keys on, the view says it uses the standard keys; in Suggest mode its text is read-only and says suggestions are made in the source. Tests: offset mapping, the round trip of caret stops, style boundaries, escaping, Enter in paragraphs, after headings and in lists, deletions across styles, the style, heading and list commands, and a hostile-input sweep (latex); typing, Enter, Ctrl+B and undo, escaping and the two-press delete of a reference through the window (kittest). Not yet: formulas and fallback spans edited in place (they still open the source), the input method's marked text (committed text is typed), Enter on an empty item leaving the list, Backspace at an item's start, PageUp/PageDown moving the caret (they scroll), Suggest mode in the formatted view, and incremental re-parsing (the file is parsed again after each edit).
