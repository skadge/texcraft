- 2026-11-28: Link to a Repository (C10; docs/design/add-remote.md). An open project is linked to a git repository that exists, from File › Link to a Repository…, the History panel (beside Save to GitHub… and Save to GitLab… while the project has no remote) or All Commands (also found as "Add a Remote"): Import a Project's dialog with its Online cards, the default connection first, and its pages without Into. Under the fields, What happens is checked on the server as typing pauses, before anything changes (`git.check_remote`): "The repository is empty: your project's history will be sent to it.", "The repository has 3 versions: they will be merged with your project's.", or "…has this project's history"; a file both sides have with other contents gets Keep mine or Take theirs there, and Link waits for each; a remote named `origin` already asks this one's name (suggested from the host). On the desktop `git.add_remote` sets the remote and the upstream and runs Sync: a version first, then a push into an empty repository or a merge of the two histories (no common version: an empty base, so files on one side are kept and the same name with other contents is chosen), then the push; never forced. A link that cannot start is undone; one stopped by a new conflict stays, and Sync's dialog settles it. In the browser GitLab and GitHub are read through their web APIs, the branch's files come in, the project is linked to the branch and Sync sends the rest (an empty GitLab repository gets the files as its first commit; GitHub's API cannot write into an empty one, and says so); Overleaf and git addresses say "Desktop app only". Unlink… (History panel, `git.remove_remote`) asks first and removes the link, touching neither side. History: `History::compare`, `remove_remote`, `clear_upstream`. Tests: engine `link.rs` (empty repository pushed and Sync after; disjoint histories merged and sent; a clash chosen both ways; `origin` taken; a link that cannot start undone; the browser on a fake GitLab), ui-egui `link.rs` (keyboard alone, the choice per file, the name and Unlink…, the cards).
