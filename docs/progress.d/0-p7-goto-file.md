- Go to File (P7): Edit › Go to File… or Ctrl+P (Cmd+P on macOS), command `view.go_to_file`, opens a palette of the project's files. Typing keeps the paths that hold the typed letters in order, best matches first (in the file's name, at word starts, in runs), with the matched letters marked; with nothing typed, the files opened most recently in this session come first. Up and Down move the selection, Enter or a click opens the file, Escape closes. The list is a list box whose selected file and match count are announced.
