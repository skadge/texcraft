- Safe updates in the browser (W10): Trunk's post-build hook, `cargo xtask version-worker`, names the engine's worker files and `retex.wasm` after a hash of their contents (`engine-worker-H_loader.js`, `engine-worker-H.js`, `engine-worker-H_bg.wasm`, `retex-H.wasm`) and writes the loader's name in `index.html` (`<meta name="texcraft-engine">`), which the app reads; the worker finds `H` in its loader's name. The tree's index and seed lists are fetched past the HTTP cache, and its files with the index's hash as a query, so an update never mixes an old tree with a new one. A build without the hook keeps the plain names, which both sides still take.
